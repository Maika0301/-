# Growing Banana (Python + Ursina)

Python 3D sample where a small, living banana suddenly grows larger and drops toward the screen. Everything is built from dotted voxel-style cubes; the banana texture is generated automatically.

## How to run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Launch the scene:
   ```bash
   python main.py
   ```

## What you will see
- A pixelated banana made of tiny cubes.
- It starts small, then expands and tumbles toward the camera.
- The animation loops automatically.
