# Michael Jackson Fan Page

Michael Jackson（キング・オブ・ポップ）のトリビュートファンページです。

## 見る

ブラウザで `index.html` を開くか、ローカルサーバーで表示してください。

```bash
python3 -m http.server 8080
```

その後 `http://localhost:8080` を開きます。

## 構成

- `index.html` — ページ構造
- `styles.css` — ビジュアル（ステージライト × クリムゾン）
- `script.js` — スクロール演出・統計カウント・瞬間カルーセル
